# slides-app

Переиспользуемый движок для докладов/воркшопов: Vite + React 19 + Tailwind v4,
без слайд-фреймворка — каждый слайд это обычный React-компонент. Управление —
клавиатура, мышь или геймпад (Xbox-контроллер), сверху таймер с разметкой по
слайдам.

## Как использовать для нового доклада

1. Склонировать/скопировать репозиторий (или сделать его шаблоном) под новый воркшоп.
2. Написать свою колоду в `src/slides/<name>.tsx` — массив `SlideDef[]` (см. `exampleSlides.tsx`).
3. Подключить в `src/main.tsx`:
   ```tsx
   <PresentationApp
     slides={MY_SLIDES}
     cuePointsSec={MY_CUE_POINTS_SEC} // опционально
     durationSec={2 * 60 * 60}        // длительность доклада, по умолчанию 2 часа
   />
   ```
4. `npm run dev` — локально, `npm run build` — для деплоя (Vercel: просто указать этот репозиторий).

## Контракт слайда

```ts
type SlideProps = {
  onDemo: (mode: string) => void  // запросить полноэкранный оверлей (см. ниже)
  slideNumber: number
  total: number
}
type SlideDef = { Component: React.FC<SlideProps> }
```

Слайд — обычный `React.FC<SlideProps>`, который рендерит `div` на весь слайд
(движок сам вписывает его в 16:9 и масштабирует под экран). Готовые примитивы
в `src/engine/primitives.tsx`:

- `TitleSlide` — титульный слайд (докладчик, тема, ссылки).
- `SectionSlide` — разделитель части доклада ("Act 1", "Часть 2" и т.п.).
- `ContentSlide` — обычный контентный слайд (заголовок + свободное тело).
- `Code` + `kw/st/cm/hl/ok/er` — блок кода с ручной подсветкой синтаксиса
  (каждый helper — это просто цветной `<span>` для одной "роли" токена:
  keyword / string / comment / highlight / ok / error).
- `Footer` — нижняя плашка с номером слайда (уже встроена в три primitives выше).

Можно верстать и с нуля на Tailwind-классах — примитивы это просто удобный
базовый набор, а не обязательный API.

## Таймер и cue-точки

`cuePointsSec[i]` — во сколько секунд от начала доклада вы ПЛАНИРУЕТЕ быть на
слайде `i`. Массив должен быть той же длины и порядка, что и `slides`. Если
время истекло, а колода ещё не дошла до этого слайда — контроллер один раз
завибрирует (незаметно для зала, заметно для докладчика в руке). Если пейсинг
не нужен — просто не передавайте `cuePointsSec`, таймер и прогресс-бар будут
работать без разметки.

## Геймпад (Xbox-контроллер)

`RB` — следующий слайд, `LB` — предыдущий, `A` или `START` — старт/пауза/
резюме таймера (первый нажатие — 3-секундный отсчёт со стартом таймера),
`B` — сброс таймера. Работает через Gamepad API (poll через
`requestAnimationFrame`, без событий) — `src/engine/useGamepadControls.ts`.

## Полноэкранное демо (`onDemo`)

Если во время доклада нужно показать что-то вживую (терминал, браузер, другое
приложение) прямо из слайда — вызовите `onDemo("какой-то-режим")` из
компонента слайда и передайте `renderDemo` в `PresentationApp`:

```tsx
<PresentationApp
  slides={MY_SLIDES}
  renderDemo={(mode, close) => mode === "terminal" ? <MyTerminalDemo onClose={close} /> : null}
/>
```
Esc или кнопка "← slides" в углу возвращают к колоде.

## Происхождение

Движок и геймпад-контролы вынесены из `JSWorld/Killing-Wasted-Re-Renders`
(презентация JSWorld 2026) и обобщены: убрано переключение между несколькими
докладами и специфичные для того доклада демо-компоненты/звуки — теперь один
деплой = одна колода, а живые демо подключаются через `renderDemo`.
